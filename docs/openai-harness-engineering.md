# Notes on Harness Engineering for Agentic Development

> Source inspiration: OpenAI writing on harness engineering and agent-led software delivery.

## Core idea

The environment around an agent is part of the product. Tools, repository structure, validation loops, and operational constraints often determine outcome quality more than prompt wording alone.

## Useful principles

- keep repository guidance short and navigable
- invest in fast feedback loops
- prefer durable artifacts over hidden context
- make approval and safety boundaries explicit
- treat tests and logs as first-class agent interfaces

## Relevance to xdev

xdev already leans heavily on tools, workflows, logs, and exported state. This document is kept as a short reminder that good harness engineering is mostly about environment design, not branding.
