## 五、浏览器自动化

基于 Playwright 的浏览器控制能力：

- **导航**: `navigate`, `back`, `forward`, `refresh`
- **交互**: `click`, `fill`, `select`, `press`, `wait`
- **获取**: `screenshot`, `content`, `text`, `html`
- **分析**: `elements`, `forms`, `links`
- **会话**: `save_session`, `load_session`（保持登录状态）

## 十二、与 originClaw 对比

### 可借鉴的点

| 特性 | originClaw | 小智现状 | 建议 |
|------|-----------|---------|------|
| 模型路由 | 智能选择 | 固定 + Skill 分流 | ✅ 可增强 |
| 权限系统 | 6层安全门 | 基础实现 | 可完善 |
| 上下文压缩 | 联动记忆 | 已实现 | ✅ |
| Worktree 隔离 | 支持 | 已实现 | ✅ |
| 成本追踪 | 详细 | 已实现 | ✅ |
| OpenTelemetry | 支持 | 已实现 | ✅ |
| 多模型支持 | 广泛 | 5个模型 | 够用 |
| Prompt 模块化 | 完善 | 已实现 | ✅ |

### 小智特色

1. **飞书原生集成** - originClaw 没有
2. **免费模型路由** - 通过 Skill 系统
3. **Worker 管理** - tmux 会话隔离
4. **Gateway 服务** - HTTP/WebSocket 端点

### 建议增强

1. **自动模型路由** - 根据任务复杂度自动选择模型
2. **权限细化** - 危险操作分级
3. **Prompt 缓存** - 相似请求复用
4. **更多 Skill** - 扩展内置技能库
