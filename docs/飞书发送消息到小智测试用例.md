# 飞书发送消息到小智测试用例

## 目标

验证“小智”通过飞书收消息、处理消息、回发消息的主链路是否可用，覆盖文本、多轮上下文、富文本 `post`、图片、文件，以及音频发送可达性。

## 前置条件

1. 小智服务已启动，且 `ws://127.0.0.1:18789/health` 与 `http://127.0.0.1:8081/health` 返回 `ok`。
2. `lark-cli auth status --verify` 与 `lark-cli doctor` 通过。
3. 使用**新建隔离私群**执行，避免旧 P2P 会话历史干扰多轮测试。
4. 本次使用的测试素材：
   - `grid.png`：标准 PNG 渐变图
   - `note.txt`：纯文本文件
   - `tone.mp3`：音频发送素材（用于验证 lark-cli 上传链路）

## 用例矩阵

| ID | 场景 | 发送方式 | 判定标准 |
| --- | --- | --- | --- |
| T01 | 纯文本单轮 | `--text` | 回复包含指定字符串 |
| T02 | 多轮上下文延续 | `--text` | 下一轮能回忆上一轮令牌 |
| T03 | 富文本/Markdown 入站 | `--markdown` | 机器人对富文本消息做出语义正确响应，不再把原始 JSON 当文本处理 |
| T04 | 未知 slash 命令 | `--text` | 立即返回 `未知命令: ...` |
| T05 | 图片消息 | `--image` | 机器人能理解图片内容并给出非空回复 |
| T06 | 文件消息 | `--file` | 机器人收到文件后给出非空回复，不崩溃 |
| T07 | 音频消息 | `--audio` | lark-cli 成功发送，且机器人给出非空回复 |

## 执行记录

### T01 纯文本单轮

- **发送内容**：`COPILOT_T01 请记住令牌 ALPHA-T01，并且只回复“已记住ALPHA-T01”。不要添加其他内容。`
- **结果**：**通过**
- **实际回复**：`已记住ALPHA-T01。`

### T02 多轮上下文延续

- **发送内容**：`COPILOT_T02 我上一条消息里让你记住的令牌是什么？只回复令牌本身，不要解释。`
- **结果**：**通过**
- **实际回复**：`ALPHA-T01`

### T03 富文本/Markdown 入站

- **发送内容**：`这是 **富文本消息测试**。请只回复“收到T03”。不要搜索文件，不要解释。`
- **结果**：**通过**
- **实际回复**：`收到，富文本消息测试正常。`
- **说明**：判定为通过，因为机器人已正确理解富文本语义；修复前，这类消息会被当成原始 JSON 或被错误路由。

### T04 未知 slash 命令

- **发送内容**：`/definitely-unknown-copilot`
- **结果**：**通过**
- **实际回复**：`未知命令: /definitely-unknown-copilot`

### T05 图片消息

- **发送素材**：`grid.png`
- **结果**：**通过**
- **实际回复**：`收到了，这是一张彩虹渐变色的纯背景图，从深蓝到青绿再到黄粉的线性过渡。`
- **说明**：最初使用 1x1 PNG 时，智谱视觉接口返回 `1210 图片输入格式/解析错误`；改用标准 PNG 后链路正常。

### T06 文件消息

- **发送素材**：`note.txt`
- **结果**：**通过**
- **实际回复**：`收到飞书发来的 note.txt 文件，让我下载并查看内容。`

### T07 音频消息

- **发送素材**：`tone.mp3`
- **结果**：**阻塞**
- **阻塞点**：`lark-cli` / 飞书上传接口返回 `HTTP 400`，错误码 `230055`：`The type of file upload does not match the type of message being sent.`
- **结论**：当前阻塞发生在**消息发送前**，尚未进入小智服务；需单独校准 `lark-cli im +messages-send --audio` 的素材格式或上传流程。

## 本次测试触发并已修复的问题

1. **飞书 `post` 入站解析缺失**：富文本消息此前无法可靠转成普通文本，已补齐解析逻辑并增加回归测试。
2. **HTTP 接收器未注入 LLM / History**：`/health` 曾误报 `LLM 客户端未初始化`，现已正确注入。
3. **启动日志与真实行为不一致**：此前日志宣称支持多条 slash 命令，但飞书入口实际统一返回未知命令；现已改为明确声明“暂未启用”。
4. **bash 工具安全规则回退**：补回 `eval`、远程脚本管道、fork bomb 等拦截规则，并恢复对应测试。
