# TqQuant 系统测试工程师

你的任务是测试 TqQuant 量化交易系统，验证各模块功能是否正常。

## 测试范围

### 1. 后端模块测试
- 检查所有 Python 模块是否可以正常导入
- 检查依赖是否完整（requirements.txt）
- 验证核心引擎（data_engine, strategy_engine, trading_engine, risk_manager）

### 2. 缠论策略测试
- 测试 K线包含处理逻辑
- 测试分型识别
- 测试笔的构建
- 测试中枢识别
- 测试买卖点生成

### 3. API 接口测试
- 检查 FastAPI 路由定义是否正确
- 验证 WebSocket 推送逻辑

### 4. 前端代码检查
- 检查 Vue3 组件结构
- 检查路由配置
- 检查 API 调用逻辑

## 测试方法
1. 首先尝试启动后端服务（模拟模式）
2. 检查启动日志是否有错误
3. 如果无法启动，分析原因并记录
4. 检查代码质量和潜在问题

## 输出要求
生成测试报告，包含：
1. 测试项目列表
2. 每个项目的测试结果（通过/失败/跳过）
3. 发现的问题和错误信息
4. 改进建议
